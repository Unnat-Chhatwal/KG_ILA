# Lecture Voice Sentiment Analysis for Knowledge Graph-Supported Lecturing Assistant System

This repository contains the source code and extracted features for our paper:

> **Is the Lecture Engaging for Learning?**  
> Yuan An, Samarth Kolanupaka, Jacob An, Matthew Ma, **Unnat Chhatwal**, Alex Kalinowski, Michelle Rogers, and Brian Smith.  
> *4th Workshop on Knowledge Graphs and Big Data (IEEE Big Data 2024)*  
> [arXiv:2408.10492](https://arxiv.org/abs/2408.10492)

---

## Project Overview
We developed a voice-based sentiment analysis system to detect **boring** vs **engaging** lectures, supporting the design of an Intelligent Lecturing Assistant (ILA). Using a dataset of over 3,000 1-minute lecture audio clips, we trained models using both spectral features and CNN-based embeddings.

---

## My Contributions
- Labeled large-scale audio datasets for supervised training
- Extracted acoustic features (MFCCs, RMS, etc.) using Librosa
- Evaluated multiple models including Random Forest, XGBoost, and CNN
- Helped achieve ~90% F1-score on independent validation
